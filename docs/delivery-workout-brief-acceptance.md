# Workout delivery: evening preparation and morning update

## Contract

- **6:00 p.m. athlete-local, email only:** Send the next local day's saved plan for preparation. Do not merely change the current email's hour; today and tomorrow are different query windows. Do not send a second routine email in the morning. A separately opted-in, explicitly labeled urgent correction must never look like routine delivery.
- **4:00 a.m. athlete-local, Telegram and Google Calendar:** Publish the current local day's briefing with a revision and approval badge. Update the JMM-owned calendar entry, not a separate 4 a.m. event. Do not send an overnight Google reminder for an untimed/held preview. Keep a default reminder only for an approved session with an actual scheduled time. Reconcile a material authorized revision in place.
- **One snapshot per revision:** Workout description, sport/session tags, purpose (why this workout), pre-workout preparation including optional reviewed stimulant guidance, warm-up, dynamics, structured workout graph and text (work/rest, intensity and prescribed pacing), during-session tags and fueling, cooldown, recovery/breathing/refueling, and energetic but supportive motivation. No shaming or encouragement to ignore the hold, pain, fatigue or warning signs. Show only authored/validated guidance; no made-up numbers, targets or supplement dosing. Publish the approved content where supported; label provisional content and keep individualized stimulus-sensitive recommendations private if not reviewed. Choose a conservative no-stimulant default when relevant context is missing.
- **Still useful before check-in:** Include the actual authored planned blocks and a labeled visual with a text alternative, not only a link. Use a saved, non-executable plan snapshot, never an adapted or stale prescription that looks approved. Link to the exact session and private check-in; the athlete can preview without checking in. Approval controls executable exports, not whether an athlete can read the schedule.
- **FIT is a backup:** Attach or link only an approved current exportable revision, when the channel and recipient are authorized. A previously approved, unchanged current revision may qualify; a provisional/changed/unsupported revision may not. Google Calendar gets a link to the signed-in workout/graph/download plus the workout text where calendar guidance is opted in, not a public file. Gmail and Telegram may render/attach the proved graphic. If a device has a stale revision, label it explicitly and do not imply it was removed. Provider acceptance is not Garmin receipt.
- **Privacy:** Separate opt-ins and verified destinations. No raw biometrics, health/safety responses, free-form notes, or private nutrition rationale in shared calendar or unverified chat. Review any expanded data-sharing consent before activation. Keep athlete and coach view on the same revision.
