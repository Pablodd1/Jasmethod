## Enforcement in the proposed version

- Coaching payload is constructed from a fixed education topic, reviewed catalog and language. It never serializes the user's words, profile, check-in, imports, sessions, derived summaries or history. Keyword checks are supplemental, not the proof of isolation.
- AI_DATA_POLICY_VERSION changes to openai-generic-education-v3. Previous AI/local-derived replies cannot become a current trusted memory or external context. Confirmed plan/profile edits remain separate owner-scoped records.
- Server validates explicit OpenAI food-photo consent and food_photo source before decoding/network; screenshot sources device/imported/unknown/missing are refused independently of consent. Declaration is not independent verification of pixel origin or Garmin permission.
- Legacy rich briefing, race and personal-context routes remain local. Intervals source restrictions and provenance checks remain intact. Automatic publication stays independently gated.
- Direct OpenAI endpoints/models are server-owned; no user-supplied base URL or provider fallback. Food-photo responses are bounded and require a completed, non-refused response; provider failure never records a meal or silently retries elsewhere.
