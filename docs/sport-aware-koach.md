# Sport references and the single Koach conversation

The athlete's conversation lives at `/coach`, labelled JMM Koach. Today retains
training, feedback and metrics, with the main navigation as the chat entry.
Both former inline conversations are removed from Today.

Profile-reference questions use authenticated local tools. The response card
shows saved values, sport, units, source and observation date (or an explicit
unknown). Cards bypass external AI and are not persisted as conversation prose
or model memory. A later question/reload clears the displayed card; a supported
sport clarification re-reads current owner records. Urgent-symptom handling
retains precedence. Other chat operations keep their existing confirmations.

Dated running pace, swimming CSS and cycling FTP reports use the existing
validated profile save with revision checks. Pace inputs use minutes:seconds
per km/mile or per 100 metres/yards, converted once into canonical units.
Personal activity results do not automatically establish these thresholds.

Dated sport-specific maximum/threshold HR reports use existing personal-record
storage, with exact labels and validated date/unit/range. Other records and old
observations remain. These are athlete reports, not verified laboratory results.
Run/bike target resolution requires the matching sport reference; stale,
unscoped or conflicting values remain unavailable. Existing model fractions and
reference-age rules remain unchanged. Explicit reviewed targets remain supported.
Swim and HYROX references can be recorded without assuming that generic HR bands
define swimming technique or station prescriptions.

The fixed cycling-minus-six-beats calculation and automatic HR-ratio VO2 estimate
are removed. Legacy shared references are labelled and collapsed in settings.
Activity peaks and demographic estimates cannot become physiological maxima.

J Metrics distinguishes visible source records from calculable load. A source
policy block shows unavailable coverage, not zero fitness or zero RPE completion.
When the period is eligible, missing actual duration/effort counts link to result
review. Unknown days, unresolved copies and restricted origins remain unknown;
no synthetic effort, partial source laundering or provider score is substituted.

No credentials, connector activation, migration, athlete measurement correction,
training-cycle replacement or external-AI data permission is part of this change.
Live device extraction and laboratory-document verification are separate work;
unknown references stay unknown until an actual supported record is available.
