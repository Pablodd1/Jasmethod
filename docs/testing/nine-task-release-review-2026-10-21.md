## Evidence interpretation and policies

The fifty-owner harness uses shared provider IDs deliberately: all queue keys, connector leases, stores, plan matching and load reads must remain owner-scoped. Duplicate webhook/poll requests create only the existing logical jobs. Four-worker batching, synthetic 429 retry, queued disconnect and in-flight revocation are exercised without provider traffic. Forty-eight active owners each keep two provider observations after the two revocation cases. Missing RPE yields unavailable load; explicit synthetic RPE makes that one actual contribute once. This does not establish a provider's fifty-athlete access tier or capacity.

`activity-store.ts` updates an owner/source/externalId record rather than inserting a duplicate, preserves cross-provider observations, and links only an unambiguous same-day/sport plan. `activity-evidence.ts` groups corroborated/explicitly reviewed copies without deleting raw rows; conflicting effort and pending decisions remain unresolved. `activity-reconciliation.ts` reads bounded owner-subject audits. `derivedActivityPolicy` blocks totals before omitting restricted contributors, so known performed work is never misrepresented as unused capacity. Existing database suites exercise persistence, correction, erasure and foreign-owner boundaries.

Lifecycle limits: the additional Intervals checks fence reads that finish after disconnect/replacement; they are not an atomic cancellation transaction spanning an entire multi-record persistence loop. Do not claim that disconnect recalls a write already in progress. The existing connector/queue controls and provider policy review remain necessary.

Cycle preference confirmation now audits the prior active plan IDs/easyPct values, saved plan ID/easyPct and the existing preview token. Both pre-confirmation and transactional reads bind those preferences; changing a preference on the same plan invalidates the preview. Profile dose updates retain the existing before/after profile audit and do not rewrite saved instructions.
