# Training protocols: evidence review and implementation

Reviewed 7 September 2026. Starting material: [shared Gemini discussion about Andy Galpin](https://share.gemini.google/uoemrzbxiIsH). The discussion was accessible in the browser and covered speed, power, hypertrophy, muscular endurance, anaerobic capacity, maximal aerobic work and aerobic base. It is a secondary AI summary, not a scientific source or an instruction to change athlete records.

The app now contains eight source-linked templates at `/protocols`, reachable from Training, Science and each administrator athlete workspace. Strength is included as a useful complement to the seven adaptations in the summary. The library supplies context to JASAI; this is prompt grounding, not model training or fine-tuning. The downloaded JSON contains the reviewed protocols, programming rules, sources and version date.

## What was retained, corrected and complemented

| Topic in the supplied material                                    | Decision in JMM                                                                                                                                                          |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Separate speed, power, size and endurance adaptations             | Retain. Select a main objective and use complementary work at a recoverable dose.                                                                                        |
| Galpin's 3-to-5 heuristic                                         | Keep as background coaching education, not a requirement to perform every variable at its maximum.                                                                       |
| Speed with long rests                                             | Retain short, technically controlled efforts. Do not prescribe assisted overspeed, a universal sprint distance or a claim of complete phosphocreatine restoration.       |
| Power from fast movement                                          | Retain maximal movement intent with low fatigue. Begin with simple movements and allow feet-grounded options; depth jumps and Olympic lifts are not defaults.            |
| 10–20 hypertrophy sets per muscle                                 | Treat higher volume as a possible progression, not an obligatory beginner minimum or proof that every trained athlete needs 20+.                                         |
| Failure and slow eccentric cadence                                | Use repetitions in reserve. Failure is optional; a fixed 2–4-second lowering phase is not necessary for all hypertrophy work.                                            |
| Endurance as four distinct categories                             | Retain. Local muscular endurance, short hard intervals, aerobic power and easy endurance have different work/rest structures.                                            |
| 4 × 4 at 90–100% HRmax                                            | Use repeatable hard efforts, with the original study's 90–95% HRmax context. Do not chase HR in the opening seconds or require 100% HRmax.                               |
| Easy training at 60–70% HRmax and nasal-only breathing            | Replace universal limits with comfortable effort/talk-test guidance. Percentage-based zones are approximations and swimming needs separate technique and breathing cues. |
| Bodyweight-based universal hydration formula                      | Prefer conditions, sweat-loss observations and individual tolerance.                                                                                                     |
| Breathing accelerates nervous-system recovery and lowers cortisol | Offer gentle breathing as optional relaxation. No automatic recovery credit or guaranteed endocrine effect.                                                              |

## Starting prescriptions

All doses below are **JMM coaching choices informed by the sources**, for generally healthy adults. They are not claims that a study tested this exact combined program. A selected athlete's existing time allowance can reduce the number of complete work sets. The preview always shows the actual prescription.

| Adaptation         | Trained starting template                                                          | How it fits an endurance program                                                                              |
| ------------------ | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Speed              | 4–6 efforts of 6 seconds; 3 minutes easy recovery                                  | Start with one exposure, while fresh. Use controlled acceleration before maximal sprinting.                   |
| Power              | Two movements, 2–3 sets of 3 reps; 3 minutes recovery                              | One or two exposures. Preserve movement quality and avoid fatiguing circuits.                                 |
| Strength           | Squat, row, press; 2–3 sets of 5 reps; 3 minutes rest                              | Usually two sessions when recoverable. Beginners use lighter six-rep practice sets and two-minute rests.      |
| Hypertrophy        | Four movement patterns, 2–3 sets of 10 reps; 2 minutes rest                        | Distribute sets across the week; endurance work already consumes recovery capacity.                           |
| Muscular endurance | Squat, incline push-up, glute bridge; 2–3 rounds of up to 20 reps; 45 seconds rest | Use when local endurance is relevant. It does not replace aerobic volume.                                     |
| Anaerobic capacity | Stationary cycling, 4–6 × 30 seconds hard/repeatable, 2 minutes easy               | Once weekly to start, replacing another hard session. Beginner assignment is unavailable.                     |
| Aerobic power      | Up to 4 × 4 minutes hard, 3 minutes easy; 10-minute warm-up and 5-minute cool-down | Once weekly to start. Beginner introduction is 3 × 2 minutes with 2-minute recoveries.                        |
| Aerobic base       | 20–90 minutes total at comfortable effort                                          | Keep most endurance work easy. Longer sport-specific training remains part of the athlete's established plan. |

Timed work periods for lifting are planning estimates. The actual instruction is the repetition count, with clean technique and adequate rest. FIT exports use repetition steps for lifting and time steps for recoveries. Protocol targets are deliberately open on the device: HR/FTP cannot represent the intended effort of a three-rep power set. The app does not infer a one-repetition maximum or maximal aerobic speed from unrelated profile numbers.

## Evidence and boundaries

- [Galpin's resistance-training episode (2023)](https://www.hubermanlab.com/episode/dr-andy-galpin-optimal-protocols-to-build-strength-and-grow-muscles) provides the adaptation framework and coaching discussion, with relevant chapters at 1:12:53, 2:28:48 and 2:55:12. [His endurance episode (2023)](https://www.hubermanlab.com/episode/dr-andy-galpin-how-to-build-physical-endurance-and-lose-fat) distinguishes four endurance targets, with protocol chapters at 2:37:30, 2:58:10, 3:16:40 and 3:21:58. These are expert teaching, not randomized trials. Public show notes and chapter lists were reviewed; premium transcripts were not accessed.
- [ACSM's 2026 position stand](https://pubmed.ncbi.nlm.nih.gov/41843416/) synthesizes 137 reviews. It supports progressive resistance training, heavier loads for strength, more weekly sets for hypertrophy and fast concentric work for power. Its adult evidence base does not validate a single universal dose or automatically extend to injured athletes and children.
- [Currier et al. (2023)](https://pubmed.ncbi.nlm.nih.gov/37414459/) found improvements with multiple resistance prescriptions; higher-load approaches ranked well for strength and multiset approaches for hypertrophy. [Schoenfeld et al. (2017)](https://pubmed.ncbi.nlm.nih.gov/27433992/) supports a volume-response relationship, without establishing the same optimum for everyone. [Robinson et al. (2024)](https://pubmed.ncbi.nlm.nih.gov/38970765/) suggests proximity to failure matters more for hypertrophy than strength, with uncertainty from estimated RIR and exploratory modeling.
- [Haugen et al. (2019)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6872694/) integrates sprint science and elite coaching. It supports individualization and high-quality sprint practice. JMM's low starting volume and 5% quality flag are operational coaching choices, not thresholds proven to prevent injury.
- [Helgerud et al. (2007)](https://pubmed.ncbi.nlm.nih.gov/17414804/) tested 4 × 4 minutes at 90–95% HRmax, with three-minute active recovery, three days weekly for eight weeks in moderately trained men. JMM starts at lower frequency because other training remains in the plan; the same effect size is not promised. [Helgerud et al. (2023)](https://pubmed.ncbi.nlm.nih.gov/37608507/) found differing aerobic and anaerobic adaptations in trained women and injuries in one all-out running protocol. The app's bike capacity template is a conservative adaptation, not the tested running intervention.
- [Woltmann et al. (2015)](https://pubmed.ncbi.nlm.nih.gov/25536539/) supports talk-test regulation during steady exercise. It does not make conversational effort a laboratory threshold measurement. The [2025 individual-participant intensity-distribution meta-analysis](https://pubmed.ncbi.nlm.nih.gov/39888556/) found no overall advantage of polarized over pyramidal training and suggests training status matters. An 80/20 or 70/30 split is not a universal law.
- [Schumann et al. (2022)](https://pubmed.ncbi.nlm.nih.gov/34757594/) found concurrent training generally compatible with muscle size and maximal strength, with possible attenuation of explosive strength, especially when performed in the same session. Separating demanding sessions is a practical option. Calendar-day recovery flags do not measure actual physiological recovery.
- [Wang et al. (2023)](https://pubmed.ncbi.nlm.nih.gov/37163550/) supports reducing endurance volume during a taper while retaining intensity/frequency. [Düking et al. (2021)](https://pubmed.ncbi.nlm.nih.gov/34489178/) reports limited, mixed performance evidence for HRV-guided training. [ACSM fluid guidance (2007)](https://pubmed.ncbi.nlm.nih.gov/17277604/) supports individualized fluid replacement and using pre/post body mass to estimate sweat losses.

## Data and implementation

Applying a protocol replaces **one selected, unfinished workout** in the active plan. The server checks athlete authorization, sport compatibility, time, injury status, days off, current check-in and nearby demanding sessions. The coach remains signed in as themselves. A preview token prevents saving an out-of-date preview. The transaction stores an audit entry with before/after data and the protocol version. Completed, imported, partially reported and skipped sessions cannot be replaced through this workflow.

The app's default scheduling limits are one hard endurance session for a beginner and two for other levels, across sports. Promoting an easy session is blocked when that limit or adjacent-day recovery checks would be exceeded. Replacing an already demanding session flags the existing schedule for review. These conservative limits are product choices, not clinical cutoffs. The app does not know movement-specific experience, all outside exercise, gym equipment or actual set velocity; the coach must review those with the athlete.

Daily adaptation reduces whole sets while retaining rest. A low-readiness or insufficient-time power/speed session becomes easy movement; rest remains zero work. The original protocol survives for a later full prescription or check-in undo. Free-form changes to sport, duration, intensity or notes supersede the protocol; simple renaming or time changes retain it.

JASAI uses the reviewed library and current saved prescription. Its HRV comparison now requires a current measurement and at least five prior measurements of the same type and source within 28 days. Missing data produces an unknown-readiness message. Completed load excludes linked duplicate plan rows and uses reported actual minutes; adherence counts fulfilled planned sessions. These changes support coaching context without turning missing data into a physiological conclusion.

Existing plans are not mass-regenerated and historical workout data is not rewritten by this release. The general legacy plan generator remains available. The new library is a deliberately selected prescription workflow; broader generator reperiodization, automatic exercise-specific load progression and a set-by-set strength log remain separate capabilities.

## Verification

Validation passed on 7 September 2026: all 23 unit test entries, 67 authenticated integration HTTP assertions, database sync/reminder regression checks, and the production build with type checking.

Unit checks cover all protocol/sport combinations, time budgets, fixed 4 × 4 intervals, full recovery, readiness reduction, restoration, cross-sport load limits, stale/mixed HRV and independent FIT decoding. Integration checks exercise preview, apply, stale preview rejection, account isolation, retained imported history, administrator audit, check-in adaptation/undo, renaming and manual edits, days off, injury flags and completed-session protection.

The local browser check used synthetic accounts: an administrator previewed and saved a selected athlete's session, expanded the source references, and downloaded the coaching reference. The JSON download contained eight protocols, 15 sources and the correct version. No production athlete prescriptions were assigned during this verification.
