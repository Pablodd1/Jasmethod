# Preserve comfortable sessions during reference review

For a saved `coaching-structure-v1` aerobic or technique session, a scheduled
comfortable reference observation is recorded within the existing session.
Its title, purpose, reviewed note and executable steps stay intact when its
effective effort is unchanged and at most Z2. The dated observation remains in
the cycle metadata and description; it does not measure or renew a threshold.

All existing duration, event, recovery, technical-work and expired-reference
caps remain unchanged. Demanding recipes and any lowered-intensity session keep
their existing conservative replacement behavior. Legacy templates are unchanged.
No training approval, automatic increase, new target, provider access or memory
export is introduced. Existing saved cycles are not rewritten.

Tests compare actual canonical steps and complete session duration for swim,
bike and run, with and without a numerical reference, and retain negative cases
for missing/expired references and recovery reductions.

This bounded correction does not establish advanced-strength eligibility,
individualized race-recovery windows or readiness for harder protocols. Those
remain distinct coaching-review requirements. A preserved easy session is not
evidence that a complete individualized performance cycle is approved.
